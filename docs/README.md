# MindVault

MindVault is a secure knowledge management system designed to allow users to capture, store, organize, and retrieve digital information.

## Project Goals

- Secure user authentication
- Capture and organize information
- Persistent data storage
- File storage
- AI-powered information retrieval
- Secure API communication

## Technology Stack

### Backend
- Python
- FastAPI
- SQLAlchemy
- PostgreSQL

### Authentication
- JWT
- Argon2 password hashing

### AI
- LangChain
- ChromaDB

### Infrastructure
- Docker
- Cloud Storage
